# Retail Store Sales Analysis Project

# Overview
This project demonstrates an end-to-end data analysis workflow using Python, Pandas, NumPy, Matplotlib, and Seaborn.

The goal is to analyze the sales performance of a retail store, identify trends, and generate actionable insights.

The dataset is synthetically generated to simulate real-world sales across multiple products, regions, and dates.

# Objectives

Generate synthetic sales data for a retail store.

Clean and preprocess data to ensure quality.

Conduct exploratory data analysis (EDA) to discover trends.

Visualize sales by product, region, and time.

Extract key insights and provide recommendations for business decisions.

# Dataset Description
Column	        Description

Date	        Transaction date

Product	        Product name/category (Laptop, Phone, etc.)

Region	        Store region (North, South, East, West)

Units_Sold	Number of units sold

Unit_Price	Price per unit

Revenue	Total revenue = Units_Sold * Unit_Price

Dataset Size: 1000 records (synthetic)

# Project Workflow
1. Data Generation
   
Synthetic dataset created using Python and NumPy.

Revenue calculated for each transaction.

3. Data Cleaning

Checked for missing values and duplicates.

Validated data types and consistency.

5. Exploratory Data Analysis (EDA)
   
Summary statistics to understand data distribution.

Aggregation by product, region, and month.

Trend analysis over time.

7. Feature Engineering

Added derived metrics like monthly revenue and product-wise sales.

9. Data Visualization

Bar charts: Revenue by Region, Units Sold by Product

Line charts: Daily Revenue Trend

Visualizations highlight key patterns and trends.

6. Insights & Recommendations
   
Top Product: Laptop generates the highest revenue

Best Region: North region leads in sales

Peak Months: March and December

# Recommendations:

Increase stock for top-selling products

Focus marketing in low-performing regions

Align inventory and staffing with peak months
